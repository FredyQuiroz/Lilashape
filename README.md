# Lilashape

[Español](#español) · [English](#english)

## Español

Interfaz histórica de Windows para mostrar el estado de un equipo y transmitir selecciones por un puerto serial. El archivo contiene las partes propias de la interfaz.

### Qué puedes hacer

- Muestra estados del equipo en una interfaz de escritorio.
- Relaciona las selecciones de pantalla con mensajes al equipo.
- Conserva el proyecto y el cuadro de diálogo que gestionaba la interfaz.

### Ejemplo

Explora el cuadro de diálogo con estados ficticios de reposo y pausa. Usa datos simulados para seguir la interfaz sin conectar equipos físicos.

### Cómo empezar

El código se creó para Windows y Visual C++. Usa las versiones de MFC o de los SDK que indiquen la solución y sus referencias. Los recursos y componentes externos de la época pueden requerir una copia autorizada. La compilación completa depende de ese entorno original.

Puntos de entrada en el código. [`lilashape.sln`](lilashape.sln), [`lilashape.vcproj`](lilashape.vcproj).

Las fechas del historial se apoyan en Git o en la evidencia disponible de los respaldos. Las fechas reconstruidas a partir de archivos sin zona horaria usan las 12:00 UTC como referencia.

## English

A historical Windows interface that displays equipment status and sends selections through a serial port. The archive contains the application's interface-specific code.

### What you can do

- Display equipment states in a desktop interface.
- Connect on-screen selections to messages sent to the equipment.
- Preserves the project and the dialog that controlled the interface.

### Example

Explore the dialog using fictional idle and paused states. Use simulated data to trace the interface without attaching hardware.

### Getting started

The code was written for Windows and Visual C++. Use the MFC and SDK versions indicated by the solution and its references. Historical resources and external components may require an authorized copy. A full build depends on that original environment.

Entry points in the source. [`lilashape.sln`](lilashape.sln), [`lilashape.vcproj`](lilashape.vcproj).

History dates come from Git or available backup evidence. Reconstructed dates from files with no time zone use 12:00 UTC as a reference.
